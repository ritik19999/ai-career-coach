# 🚀 AI Career Coach (Gemini Powered)

AI-powered career intelligence system that analyzes resume, job description, and self profile using Google Gemini to generate interview insights, skill gaps, and JD-specific optimized resumes with PDF export.

---

## 🧠 Problem It Solves

Job seekers struggle with:
- Not knowing their real match with job roles
- Lack of structured interview preparation
- Generic resumes not tailored for each job description

This system solves it using AI.

---

## ⚙️ Input

- Resume
- Job Description
- Self Description

---

## 📊 Output Generated

- Match Score (0–100)
- Skill Gap Analysis
- Technical Interview Questions
- Behavioral Questions
- AI-generated Answers
- Personalized Preparation Plan
- JD-specific Resume
- Downloadable PDF Resume

---

## 🤖 AI Engine

Powered by:
- Google Gemini API
- Prompt-engineered structured outputs
- JSON-based response formatting

---
